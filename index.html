Run the full app

This page is the static showcase

The interactive platform — live maps, the login gate, and the /dispatch console — needs the FastAPI backend and Next.js server. They can't run on GitHub Pages, so run them locally: 

# terminal 1 — backend
python -m uvicorn backend.main:app --port 8000

# terminal 2 — frontend
cd frontend && npm install
npm run dev   # → http://localhost:3000
# demo Field Officer login
officer ID   : OFF-SKM-001
district     : Mangan  (Sikkim)
access code  : SKM482

# citizens log in with just
# their full name + home state
Note: visiting the repo root on GitHub Pages shows this static page only. Open the live app at localhost:3000 for the full experience — including the role-gated hard gate, the risk map, and the dispatch console.
